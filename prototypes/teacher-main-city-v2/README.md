# 教师主城区真实空间原型 v2

这是 v1 的高保真空间版本，仍然是独立原型，不连接正式 API，不启动 Phaser，不写入数据库。

## 预览

需要在仓库根目录启动：

```bash
python3 -m http.server 4174 --directory prototypes/teacher-main-city-v2
```

打开 <http://localhost:4174>。

## 本版变化

- 从卡片式示意改成完整办公室空间。
- 顶部加入 Agent Guild、Task Board、Status、Announcement 信息墙。
- 场景加入墙面、灰砖地面、木质前台、植物、人物阴影和家具层次。
- 保留教师只读观察模式和点击人物查看状态。
- 左侧区域导航明确对应大厅、工位区、协作室、评审区。

## 请重点判断

1. 这个空间比例是否比 v1 更接近你想要的真实办公室。
2. 顶部信息墙是否应该保留，还是减少信息密度。
3. 左侧区域导航是否应该改回顶部 Tab。
4. 人物现在的大小、站位和信息标签是否合适。
5. 教师右侧观察面板是否需要更强的课堂控制入口。
