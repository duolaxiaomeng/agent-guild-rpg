# 教师主城区交互原型

这是独立于正式 `apps/web` 的判断用原型，不连接 API、不依赖 Phaser、不写入数据库。

## 预览

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory prototypes/teacher-main-city
```

然后打开 <http://localhost:4173>。

## 本轮验证重点

1. 教师工作台是否需要明确的“进入我的主城区”入口。
2. 进入主城区后，区域导航放在左侧是否比顶部更清晰。
3. 点击学生角色后，右侧只读观察面板是否足够表达状态。
4. “教师观察模式”是否和学生操作模式有明显区别。
5. 需要保留哪些按钮，哪些按钮应该隐藏到后续版本。

## 当前不代表正式实现

- 场景中的人物、桌子和背景是 CSS 原型块，不是最终 Phaser 资产。
- 区域切换目前只改变标签和反馈，不加载真实场景。
- “查看学生房间”“课堂控制”“世界频道”只显示原型提示。
